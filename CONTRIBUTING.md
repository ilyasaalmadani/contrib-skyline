# Contributing to contrib-skyline

Thank you for your interest in making contribution visualizations better!

## How to Contribute

1. **Fork** the repository
2. **Create** a branch (`git checkout -b feature/amazing-theme`)
3. **Commit** your changes
4. **Push** and open a Pull Request

## Ideas Welcome

- New themes
- Better isometric math
- Animation improvements
- Real data integration
- Documentation
- Bug fixes

## Code Style

- Python 3.8+
- Clear function names
- Comments for complex math
- Keep SVGs lightweight

## Questions?

Open an issue or reach out.

Happy contributing!
